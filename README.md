## Kata de "arnold-enum-types" en Java

Orientado del: https://github.com/dfleta/richttps://github.com/dfleta/arnold-enum-type.git
### Descripción:

Es un kata orientado al enum en Java.

Se trata de calcular el peso de una persona en los distintos planetas de nuestro Sistema Solar

## Tecnologías utilizadas

- **Lenguaje:** Java 21
- **Build Tool:** Maven
- **Testing:** JUnit 4
- **IDE:** IntelliJ IDEA / VS Code

---

## Cómo ejecutar el proyecto

### Maven:

```bash
# Compilar el package del proyecto:
  mvn clean package
# Ejecutar tests:
  mvn test
# Ejecutar el JAR:
  java -jar target/Arnold-1.0-SNAPSHOT.jar
```
